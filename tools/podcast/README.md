# Конвейер монтажа подкаста

Скрипты запускаются из рабочей папки эпизода (`raw/IMG_xxxx.MOV` внутри).

1. `transcribe.py` — расшифровка по словам (faster-whisper large-v3-turbo).
2. `align.py` — точное выравнивание слов по звуку (wav2vec2 ru) + что звучит в паузах.
3. `gaps.py` — паузы с голосом (кандидаты в «ээ/мм» и дубли).
4. `build_edl.py` — монтажный лист: слова-паразиты, дубли (индексы слов задаются вручную), паузы >0,5 с → 0,2 с, точка вставки интро.
5. `build_voice.py` — голосовая дорожка по монтажному листу.
6. `qa.py` → `pass2.py` — повторная расшифровка смонтированного звука и добивание оставшихся паразитов.
7. `graphics_spec.py` (+ `anchors.py`) — графика, привязанная к фразам.
8. Видео: `ffmpeg -filter_script:v select.txt` (выборка по номерам кадров после `fps=30`).
9. Remotion: композиция `Episode1` (`remotion/src/episode`), звук: `remotion/src/episode/mix_episode.py`.
